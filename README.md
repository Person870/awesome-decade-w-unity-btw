# awesome-decade-w-unity-btw

it's a repo but here is the assignment with a bunch of game dev tools 

Unity - A widely-used game engine that supports both 2D and 3D games. It uses C# for scripting and has a large asset store, extensive documentation, and strong community support.
https://unity.com/

Defold - A lightweight game engine that is especially good for 2D games. It uses Lua and includes tools for editing, testing, debugging, and building games.
https://defold.com/

Fyrox - An open-source Rust game engine that supports both 2D and 3D games. It also has its own editor for creating and managing projects.
https://fyrox.rs/

Stride - An open-source game engine that uses C#. It supports both 2D and 3D games and works well with the .NET ecosystem.
https://www.stride3d.net/

LDtk (Level Designer Toolkit) - A tool for creating 2D game levels. It is useful for making tile-based maps and organizing things like layers and game objects.
https://ldtk.io/

TrenchBroom - A 3D level editor mainly used for games with Quake-style level design. It focuses on building and editing 3D environments.
https://trenchbroom.github.io/

Pixelorama - An open-source pixel-art program for making sprites, tiles, and animations. It is a useful option for creating artwork for pixel-based games.
https://orama-interactive.itch.io/pixelorama

OGMO Editor - A free level editor for 2D games. It can be used to create maps and organize tiles, objects, and different layers.
https://ogmo-editor-3.github.io/

Bosca Ceoil: The Blue Album - A simple music-making tool for creating melodies and basic game music. It is easier to get started with than many full music programs.
https://yurisizov.itch.io/boscaceoil-blue

Bfxr - A simple tool for creating game sound effects, especially retro-style sounds. It lets you generate sounds and adjust things like pitch and filters.
https://www.bfxr.net/
